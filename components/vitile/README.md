# vitile — плитка окон для KDE Plasma в духе Hyprland

Скрипт для KWin (Plasma 6, Wayland), который раскладывает окна плиткой, как Hyprland:
спираль (dwindle), управление с клавиатуры, отступы, цветная рамка со скруглением,
анимации появления, закрытия и перестройки.

Всё ставится только в домашнюю папку и полностью удаляется одной командой:
настройки KDE, которые vitile меняет, запоминаются и при удалении возвращаются.

## Установка и удаление

```fish
python3 ~/programming/linux/kde_zephyr/components/vitile/vitile.py install     # поставить и включить
python3 ~/programming/linux/kde_zephyr/components/vitile/vitile.py apply       # применить settings.ini после правки
python3 ~/programming/linux/kde_zephyr/components/vitile/vitile.py uninstall   # убрать всё и вернуть как было
python3 ~/programming/linux/kde_zephyr/components/vitile/vitile.py help        # справка (то же, что Meta+Shift+F1)
```

Повторный `install` безопасен: им же обновляется установленная версия.

## Клавиши

| Клавиши | Что делает |
|---|---|
| `Meta + ← → ↑ ↓` | перейти на соседнее окно |
| `Meta + Shift + ← → ↑ ↓` | поменять окно местами с соседом |
| `Meta + Alt + → / ←` | окно шире / уже |
| `Meta + Alt + ↑ / ↓` | окно выше / ниже |
| `Meta + F` | развернуть окно; остальные уезжают в ленту за край экрана (как в niri). Повторно — обратно в плитку |
| `Meta + Space` | открепить окно: плавает по центру поверх всех; повторно — вернуть в плитку |
| `Meta + Q` | свернуть окно |
| `Meta + Shift + Q` | вернуть последнее свёрнутое |
| `Meta + M` | закрыть окно |
| `Meta + Shift + T` | выключить / включить плитку **на этом рабочем столе** (запоминается; без плитки — обычные заголовки с крестиком) |
| `Meta + Shift + F1` | справка по клавишам и настройкам |
| `Meta` + левая кнопка мыши | перетащить окно; бросить на другое — поменяются местами |
| `Meta` + правая кнопка мыши | тянуть за край — изменить размер |

Клавиши меняются в `settings.ini`, раздел `[keys]` (см. ниже), и `vitile.py apply`.

## Настройки — `settings.ini`

| Ключ | Что задаёт |
|---|---|
| `[layout] outer_gap` | отступ от краёв экрана и от панели, пиксели |
| `[layout] inner_gap` | расстояние между окнами, пиксели |
| `[layout] top_gap` | зазор от плавающей панели сверху или сбоку; `1` — ближе всего, пока панель ещё плавает (Plasma прилепляет её, как только окно касается её области) |
| `[layout] exclude` | программы, которые плитка не трогает (класс окна через запятую) |
| `[border] width` | толщина рамки, пиксели |
| `[border] radius` | скругление углов; не больше ~3,4 × толщина рамки |
| `[border] active_color` | цвет рамки активного окна, `#RRGGBB` или `#RRGGBBAA` |
| `[border] inactive_color` | цвет рамки остальных окон |
| `[animation] enabled` | анимации: `yes` / `no` |
| `[animation] duration` | длительность анимаций, мс |
| `[animation] popin_scale` | с какого размера «выпрыгивает» новое окно (`0.85` = 85%) |
| `[animation] move` | плавно двигать окна при перестройке плитки: `yes` / `no` |

| `[keys] …` | горячие клавиши: `focus_left = Meta+Left`, `close = Meta+M` и т.д. (`none` — без клавиши) |

После правки — `vitile.py apply`. Если сочетание занято другой программой KDE, vitile его не
отбирает, а пишет, кем оно занято; опечатки и повторы тоже показывает.

## Как устроено

| Часть | Где лежит в проекте | Куда ставится |
|---|---|---|
| Плитка, клавиши, всплывающие окна | `script/` (KWin-скрипт на JS) | `~/.local/share/kwin/scripts/vitile` |
| Анимации | `effect/` (KWin-эффект на JS) | `~/.local/share/kwin/effects/vitile_motion` |
| Рамка (основная) | `decoration/` (модуль KDecoration3 на C++), сборка в `build/` | `~/.local/lib/qt6/plugins/org.kde.kdecoration3/org.kde.vitile.so` |
| Где KWin ищет рамку | генерируется установщиком | `~/.config/environment.d/vitile.conf` (`QT_PLUGIN_PATH`, действует после входа в систему) |
| Проверка после входа | служба systemd | `~/.config/systemd/user/vitile-check.service` |
| Рамка (запасная) | генерируется из `settings.ini` (тема Aurorae) | `~/.local/share/aurorae/themes/vitile-a` или `vitile-b` |
| Переключение рамки, справка, режим столов | генерируются установщиком (службы systemd) | `~/.config/systemd/user/vitile-deco@.service`, `vitile-help.service`, `vitile-desk@.service` |
| Настройки KWin | — | несколько строк в `~/.config/kwinrc` |

Что vitile меняет в KDE и возвращает при удалении (копия старых значений — в `.backup.json`):

- **рамка окон**: пока плитка включена — своя тема, при выключении и после удаления — прежняя;
- **клавиши**: `Meta + стрелки` (прилипание к половине экрана), `Meta + Shift + ←/→`
  (перенос на другой монитор), `Meta + Alt + стрелки` (переключение окон), `Meta + Q`
  (переключатель комнат);
- **эффекты**: встроенные «Масштаб» и «Затухание» (появление и закрытие окон) выключены,
  их заменяет `vitile_motion`.

### Рамка: JavaScript + C++

Логика (плитка, лента, клавиши, столы) — KWin-скрипт на JavaScript. Рамка — свой модуль
на C++ (`decoration/`): у каждого окна свой вид. Окно в плитке скрипт помечает
(`keepBelow` — плитки и так держатся под плавающими окнами и диалогами), и рамка рисует его
без заголовка, с тонкой цветной обводкой и настоящими скруглёнными углами — скругление и
обводку делает сам KWin, поэтому скругляется и содержимое окна. Остальные окна — с
заголовком и кнопками в цветах системной схемы. При смене стола ничего не переключается,
поэтому она мгновенная.

- **Сборка**: `vitile.py build` (нужны `cmake`, `extra-cmake-modules`, заголовки `kwin`/`kdecoration`
  — в Arch они уже в пакетах). `install` собирает сам.
- **Первый раз** после установки нужно выйти из системы и зайти снова: KWin узнаёт о модуле
  из окружения сеанса. До этого работает запасная рамка.
- **Запасной путь**: если модуль не загрузился (например, после обновления KDE), vitile
  включает прежнюю тему Aurorae — всё работает, только смена столов снова с задержкой.
  После входа в систему служба `vitile-check` сама пересобирает модуль, если KDE обновился.
- **После крупного обновления KDE** сборка идёт начисто (кэш сборки помнит пути к старым
  библиотекам). Перед тем как включать рамку на новом KWin, её можно проверить на стенде —
  отдельном невидимом KWin, который не затронет рабочий стол:
  `dbus-run-session -- ~/programming/linux/kde_zephyr/components/vitile/tests/nested_test.sh`
- **Если что-то пошло совсем не так** (KWin не стартует): в консоли (Ctrl+Alt+F3)
  `rm ~/.config/environment.d/vitile.conf` и войти снова — KWin не найдёт модуль и возьмёт
  стандартную рамку.

Особенности поведения:

- **Раскладка dwindle.** Каждое новое окно делит пополам оставшееся место по длинной стороне
  и встаёт рядом с активным.
- **Лента как в niri.** Когда окно развёрнуто (`Meta + F`), стол переходит в ленту: окна стоят
  колонками в ряд, развёрнутое занимает весь экран, остальные (по половине экрана) — за краем.
  Переключился на другое окно (Alt+Tab, `Meta + ←/→`, клик) — лента прокручивается, и окно
  въезжает целиком рядом с развёрнутым, а не поверх. `Meta + Alt + ←/→` меняет ширину колонки.
  `Meta + F` на развёрнутом окне — обратно в плитку, как было.
- **Плитка по рабочим столам.** `Meta + Shift + T` выключает плитку только на текущем столе;
  это запоминается (`offDesktops` в `kwinrc`). Рамка общая на все столы, поэтому при переходе
  на стол с другим режимом она переключается сама. Рамка переключается ~0,3 с, поэтому на это
  время окна нового стола прячутся и потом плавно проявляются уже с нужной рамкой — без
  мелькания заголовков и дёрганья. Если включено «Скольжение» между столами, рамка
  переключается после того, как оно доедет (иначе анимация спотыкается).
- **Запись настроек.** `vitile.py` правит `kwinrc` под той же блокировкой, что и KDE
  (`kwinrc.lck`), и атомарно (временный файл + подмена), поэтому одновременные службы
  не теряют правки друг друга.
- **Минимальные размеры.** Раскладка учитывает, меньше какого размера окно быть не может
  (Brave ~510 px в ширину, OnlyOffice 800×738). Если места физически не хватает
  на все окна, нехватка делится поровну между ними.
- **Всплывающие окна.** Диалоги и окна фиксированного размера появляются по центру. Постоянное
  «поверх всех» им не ставится (иначе оно повисло бы на играх в окне и заставках программ):
  окна в плитке и так держатся под остальными.
- **Полноэкранный режим** (видео на весь экран, игры): окно выходит из плитки, теряет пометку
  «в плитке» и поднимается над панелью; после выхода возвращается на своё место.
- **Картинка в картинке** из браузеров в плитку не берётся и висит поверх всех.
- **Программы, которые сами меняют размер окна** (VLC подгоняет окно под видео, некоторые
  программы восстанавливают свой прошлый размер): vitile возвращает окно в его ячейку. С упрямыми
  программами не спорит бесконечно — не больше 6 возвратов за 3 секунды. mpv держит пропорции
  видео сам; чтобы он заполнял ячейку, в `~/.config/mpv/mpv.conf` добавь `keepaspect-window=no`.
- **Чужие настройки окон не трогаются**: пометку «держать под остальными» vitile снимает только
  с окон, которым поставил её сам; рамку программам со своим заголовком не возвращает.
- **Системные поверхности не трогаются.** Окна, которые нельзя двигать (панели, громкость,
  подсветка, окошки у трея вроде Asus Helper, карточка Whisper — чаще всего это layer-shell),
  vitile не ставит по центру, не прячет при смене стола и не анимирует: их положением
  управляет сама программа и KWin.
- **Плавающая панель.** Окна не заходят в её «воздух», иначе Plasma приклеивает её к краю.
- **Скругление углов** сделано темой рамки: скругляется внешний край. Поэтому радиус
  ограничен ~3,4 × толщина, иначе из-под рамки выглянет прямой угол окна.
- **Программы со своим заголовком** (Brave, Chrome, часть GTK) рамку vitile не получают.
  В Brave включи `brave://settings/appearance` → «Использовать системные заголовки и границы окон».

## Тесты

```fish
python3 ~/programming/linux/kde_zephyr/components/vitile/tests/live_test.py                       # всё (~25 минут; удобнее группами)
python3 ~/programming/linux/kde_zephyr/components/vitile/tests/live_test.py test_open_many test_move   # выборочно
```

Живой тест на текущем рабочем столе. Он открывает свои окна (kitty, Dolphin, Brave, OnlyOffice),
жмёт клавиши vitile и после каждого шага проверяет:

- окна не перекрываются и не вылезают за экран;
- свободное место занято;
- ни одно окно не меньше своего минимума;
- диалоги стоят по центру.

Закрывает тест только свои окна. `WARN` означает, что окна физически не помещаются в свои
минимальные размеры, это не ошибка.

Отладка: KWin-скрипт и эффект пишут ошибки в `journalctl --user -b | grep -i vitile`.
